# TwinJEPA

Action-preferred predictive representations for goal-conditioned control.

**Feiran You · Hongyang Du**  
The University of Hong Kong

TwinJEPA keeps the TD-JEPA backbone and adds offline-mined reward-gap and preference supervision, with no extra cost at inference.

## Links

- Project page: https://feiranyou.github.io/twinjepa/
- Paper: https://arxiv.org/abs/2610.02922

## Results on the project page

Matched Fixed-HP lifts include ExORL Quadruped **+40.4**, ExORL Cheetah **+33.7**, DMC Walker **+8.4**, D4RL Maze2D **+5.2**, and OGBench AntMaze medium-navigate **+4.4**. Demos, task-level figures, and the citation are on the project page.
